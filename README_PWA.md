# Gym App — PWA

This version is installable as a Progressive Web App (PWA).

## Test locally

```bash
npm install
npm run dev
```

Open the app in Chrome. For the full install prompt, use a deployed HTTPS URL (localhost is also allowed by Chrome for local PWA testing).

On Android Chrome: open the site → browser menu → **Install app** / **Add to Home screen**.

The app includes a manifest, app icons, a service worker, standalone display mode, and an in-app Install button when the browser exposes the install prompt.
