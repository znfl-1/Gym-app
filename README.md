# Gym App — Frontend v3

Current functionality:
- Responsive mobile-first dashboard
- Supabase authentication with magic link
- Live workout plans and exercise library from Supabase
- Exercise search and details
- Active workout with editable weight/reps
- Completed sets saved to `workout_sets`
- Completed sessions saved to `workout_sessions`
- Body-weight entries saved to `progress_entries`
- Progress UI

The app can still display demo data when Supabase environment variables are not configured.
